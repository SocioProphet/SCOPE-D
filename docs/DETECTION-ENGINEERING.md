# SCOPE-D Detection Engineering v0.1

Status: executable candidate-generation slice

## Purpose

Detection Engineering v0.1 converts receipt-backed intelligence observations into reviewable defensive detection candidates.

The output is not a deployed control. It is a governed candidate bundle that can be reviewed by an operator, explained by a defensive model workflow, and routed to lab or edge assurance surfaces.

## Inputs

```text
IntelligenceEnrichment
  -> IntelligenceObservation[]
  -> IntelligenceReceipt[]
  -> DetectionCandidateExport
```

The input must be generated by the SCOPE-D Intelligence Fabric and must have `executionPerformed=false`.

## Outputs

The first candidate exporter emits candidate records for these families:

- Sigma
- YARA
- OSQuery
- OPA/Rego
- Suricata
- GitHub policy
- SourceOS policy

Each candidate includes:

- source observation reference;
- source evidence receipt references;
- ATT&CK mapping;
- rule body;
- deployment target;
- operator approval requirement;
- provenance and confidence;
- WhiteRabbitNeo defensive review provenance.

## CloudShell Fog placement

CloudShell Fog is modeled as an authorized edge operator bastion and mesh node.

Allowed modes:

- lab review;
- read-only observation;
- policy-gated delivery;
- mesh edge assurance.

Prohibited modes:

- unauthorized access;
- stealth persistence;
- payload execution;
- credential collection;
- log mutation;
- public scanning.

In v0.1, CloudShell Fog receives only candidate eligibility metadata. It does not execute detections, scan public targets, mutate infrastructure, or deploy controls. Any future delivery path must be authorized by operator policy and produce receipts.

## WhiteRabbitNeo workflow placement

WhiteRabbitNeo is modeled as a defensive detection review assistant.

Allowed use:

- rule explanation;
- false-positive review;
- coverage-gap review;
- safe lab detection triage.

Blocked use:

- payload creation;
- evasion guidance;
- credential theft;
- unauthorized exploitation;
- destructive action.

Every WhiteRabbitNeo-assisted output must be grounded in SCOPE-D receipts, observations, cases, or proof artifacts.

## Current command

```bash
npm run detection:export -- <intelligence-enrichment.json> --out <detection-candidates.json>
npm run test:detection
```

## Non-claims

This slice does not:

- deploy Sigma/YARA/OSQuery/OPA/Suricata rules;
- execute endpoint queries;
- run packet inspection;
- call an LLM;
- call WhiteRabbitNeo;
- perform active scanning;
- deliver controls to CloudShell Fog;
- modify production systems.
